# Runbook: Progressive Periodization & Long-Term Program Design
Signatures: "program", "routine", "periodization", "mesocycle", "specialization", "long-term plan", "progression", "roadmap"

## 1. Training-Age Blocks
When building a full progressive program for a muscle group or lift (not a single session), structure it across three training-age blocks:

*   **Beginner (Weeks 1–8) — Form and Foundation:** Prioritize movement quality and consistent volume over load. Use moderate, fixed rep ranges (10–12+) and simpler exercise variations (standard barbell/dumbbell basics) before introducing machines or advanced variants. Structure this block as 2-week waves, introducing at most one new variation per wave.
*   **Intermediate (Weeks 9–20) — Hypertrophy and Volume:** Shift focus to volume accumulation and progressive overload. Increase set count (moving toward 4 working sets), introduce moderate-to-heavy compound-lift variations, and begin adding machine or cable variations for controlled overload. Structure this block as 4-week waves.
*   **Advanced (Weeks 21+) — Specialization and Intensity:** Prioritize intensity techniques over raw volume increases. Introduce advanced/specialized variations and intensity techniques (drop sets, paused reps, narrow-grip or drag variations, concentration/spider-style isolation work). Structure this block as 4-week waves.

## 2. Program Formatting Rules
When an athlete requests a full periodized program:

1.  Label each training-age block with its week range and one-line focus (e.g. "Beginner (Weeks 1–8) — Form and foundation").
2.  Under each block, break progress into the wave lengths defined above (2-week waves for Beginner, 4-week waves for Intermediate/Advanced), each with a short label (e.g. "W1–2", "W9–12").
3.  Under each wave, list exercises as "Exercise Name Sets×Reps" (e.g. "Barbell Curl 3×10–12"). List 2 exercises per wave.
4.  Pull exercise names from the Move Selection Matrix (see the workout-programming runbook) for the relevant muscle group — use the Primary Compound Lift early in a block and rotate through the Isolation Alternates as the athlete progresses through waves, rather than repeating one exercise for the entire block.
5.  Rep ranges should tighten and loads should trend heavier moving from Beginner → Intermediate → Advanced, consistent with the shift from form-building to hypertrophy to intensity described above.

## 3. Calibrating to a Known Athlete
If the athlete's experience level is already known (stated by the athlete or saved in their profile):

*   Start the displayed program at their current block rather than re-walking them through a block they've already progressed past.
*   Still display the remaining blocks ahead of their current one, so they can see the full long-term roadmap rather than only the immediate block.
*   If experience level is unknown and the athlete is asking for a full program, ask which block they're currently in before defaulting to Beginner — a genuinely advanced athlete given a Beginner program is a real program-design failure, not just a minor inconvenience.
